# 🎯 Number Guessing Game

A simple and interactive **Number Guessing Game** built with HTML, CSS, and JavaScript.

The game generates a random number within a selected range, and the player tries to guess it. After each attempt, the game provides a hint indicating whether the guess is **too high** or **too low** until the correct number is found.

## 🚀 Live Demo

👉 **[Play the Number Guessing Game](https://hasini26-g.github.io/NumberGuess/)**

## ✨ Features

* 🎲 Random number generation
* 🔢 Custom number range
* 💡 Higher/lower hints after each guess
* 🔄 New game / reset functionality
* ♾️ Unlimited guesses
* 📱 Responsive interface
* 🎨 Clean and simple UI
* ⚡ Runs entirely in the browser

## 🛠️ Tech Stack

* **HTML5** — Structure and layout
* **CSS3** — Styling and responsive design
* **JavaScript** — Game logic, random number generation, user input handling, and DOM manipulation

## 🧠 How It Works

1. The player selects or enters a number range.
2. The game generates a random number within that range.
3. The player enters a guess.
4. JavaScript compares the guess with the generated number.
5. The game displays a hint:

   * **Too high** — the guess is greater than the secret number.
   * **Too low** — the guess is smaller than the secret number.
   * **Correct** — the player has found the secret number.
6. The player can start a new game and try again.
